Promo code patterns
Discount badge → amber tint
Fixed amount badge → blue tint
Offline payment badge → purple tint
Group unlock badge → green tint
Simple codes → dropdown behavior selector (single flag)
Combo codes → checkbox behavior flags (multiple flags)
Each checked flag reveals its inline config fields
Security note appears on all codes — enumeration prevention
Unlimited / None shown as text inputs for limit fields when unset
Code string field → monospace, uppercase — matches customer entry experience
Inclusions on codes → same 3 types as packages (shoe rental, food, game credits)
Code inclusions merge with package inclusions — additive not replacing
Shoe rental toggle on code → simple on/off, no size config needed at code level
