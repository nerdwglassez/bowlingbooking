Modification navigation model
Detail → Overview → Field editor → Overview → Detail (5 states)
Each layer slides up — back chevron label names the parent: "Modify" or "Detail"
Field editor header: back to "Modify" · no cancel needed
Apply button label includes selected value — "Apply — Lane 5"
Overview dims to 18% behind field editor
Changed field: amber tint + new value amber + strikethrough original
Save disabled until at least one change applied
After save: detail shows "Updated" green badge + updated row highlighted
"← was 4" inline note fades after ~3s in real implementation
All changes committed atomically — single PATCH to booking endpoint
Save button label: "Save N change(s)" — count reflects pending changes
Contact row in detail: email + phone as amber tappable links
Cancel: reason required · refund toggle (Manager+ only) · slides up same as field editor
Post-cancel: Cancelled + Refunded badges · payment strikethrough + refund note · audit trail
Audit trail: reason, cancelled by (name + role), timestamp
