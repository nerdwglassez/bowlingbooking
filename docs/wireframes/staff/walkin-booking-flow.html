Walk-in flow patterns
Bottom sheet — cockpit dims to 18% opacity behind it
3 step dots in sheet header — active dot is wider amber pill
Source defaults to Walk-in — Phone and Advance available
Email optional — guest note explains why
Bowler stepper shows lane count inline (4 bowlers = 1 lane)
Package dropdown — defaults to "No package", scales to any number of packages
Auto-assign shows next available lane with Override button
Override reveals mini lane grid — same state colors as cockpit lanes view
Booking created as CHECKED_IN immediately — no hold, no Stripe
Payment method recorded for staff reference — Cash / Card / Tab
CTA: "Create & check in" — one action, two outcomes
