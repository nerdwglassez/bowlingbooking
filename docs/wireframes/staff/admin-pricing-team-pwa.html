PWA Manifest Config Spec
Web App Manifest
Two manifests — one per app surface. Staff and customer apps get separate icons, names, and start URLs so each saves as a distinct home screen app.
File locations
public/ manifest-customer.json ← customer booking app manifest-staff.json ← staff cockpit app icons/ customer-192.png ← amber on stone customer-512.png staff-192.png ← amber on purple staff-512.png
Customer manifest
{ "name": "Royal Z Lanes", "short_name": "Royal Z", "description": "Book lanes at Royal Z Lanes", "start_url": "/", "display": "standalone", "background_color": "#F5F2EE", "theme_color": "#1E0A2E", "orientation": "portrait", "icons": [ { "src": "/icons/customer-192.png", "sizes": "192x192", "type": "image/png" }, { "src": "/icons/customer-512.png", "sizes": "512x512", "type": "image/png", "purpose": "any maskable" } ] }
theme_color sets the iOS/Android status bar color. Using --surface-dark (purple) matches the app header. Customer sees amber-on-stone icon.
Staff manifest
{ "name": "Royal Z — Staff", "short_name": "RZ Staff", "description": "Royal Z Lanes staff operations", "start_url": "/staff", "display": "standalone", "background_color": "#1E0A2E", "theme_color": "#1E0A2E", "orientation": "any", "icons": [ { "src": "/icons/staff-192.png", "sizes": "192x192", "type": "image/png" }, { "src": "/icons/staff-512.png", "sizes": "512x512", "type": "image/png", "purpose": "any maskable" } ] }
orientation: "any" lets staff rotate to landscape on iPad. start_url: "/staff" means saving to home screen always opens cockpit. Staff icon: amber on deep purple.
Next.js head tags
// app/layout.tsx — customer app root <link rel="manifest" href="/manifest-customer.json" /> <meta name="apple-mobile-web-app-capable" content="yes" /> <meta name="apple-mobile-web-app-status-bar-style" content="black-translucent" /> <meta name="apple-mobile-web-app-title" content="Royal Z" /> // app/staff/layout.tsx — staff app root <link rel="manifest" href="/manifest-staff.json" /> <meta name="apple-mobile-web-app-capable" content="yes" /> <meta name="apple-mobile-web-app-title" content="RZ Staff" />
apple-mobile-web-app-capable is required for iOS Safari full-screen mode. Without it the address bar stays visible even after saving to home screen.
Multi-tenant note
Manifest name and short_name come from tenant record — not hardcoded. getTenant() returns tenant.name for use in the manifest route handler. Each venue's saved app shows their name on the home screen, not a generic platform name. Implementation: create app/manifest-customer.json/route.ts as a dynamic route that reads tenant from the request subdomain and returns the manifest JSON with tenant.name injected.
What staff need to tell their team
Safari → visit your staff URL → Share button → "Add to Home Screen" → tap Add. Takes 10 seconds. The app icon appears on the home screen and opens full-screen with no browser chrome. Works identically on iPad and iPhone.
